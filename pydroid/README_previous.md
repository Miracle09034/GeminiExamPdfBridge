# Gemini Exam HTML → A4 PDF (Pydroid 3)

## What this does

This converter is designed for the HTML exam papers generated by Gemini.

Pipeline:

Gemini HTML + local assets → Android WebView/Chromium → A4 PDF

It does **not** try to reinterpret your HTML in Python. The HTML is rendered by Android's
WebView, so CSS layout, SVG, local PNG/JPG images, fonts, Grid/Flexbox, borders, etc.
are handled by the browser engine.

## Important

This version is intended to run as a **Kivy application inside Pydroid 3**, because Android's
WebView is an Android UI component and needs an Activity/Android context.

### Install in Pydroid 3

1. Make sure Pydroid 3's **Pydroid repository plugin** is installed.
2. In Pydroid's pip settings, keep **Use prebuilt libraries repository** enabled.
3. Install Kivy using Pydroid's quick-install/prebuilt package mechanism.
4. Install the small WebView package if you want it available for other projects:

   pip install webview-android

The converter itself uses Android WebView through PyJNIus. If your Pydroid installation
does not already provide `jnius` and `android.runnable`, install/enable the corresponding
Kivy/Python-for-Android support from Pydroid's prebuilt repository rather than forcing a
native source build.

## First test

Put these files together:

/storage/emulated/0/ExamPapers/
    paper.html
    logo.png

Then run:

python html_to_pdf.py "/storage/emulated/0/ExamPapers/paper.html"

It should create:

/storage/emulated/0/ExamPapers/paper.pdf

Or specify an output path:

python html_to_pdf.py \
  "/storage/emulated/0/ExamPapers/paper.html" \
  "/storage/emulated/0/ExamPapers/Primary3_Phonics.pdf"

## Why this architecture

Your Gemini HTML is already a browser document. Android's WebView supports loading HTML
and creating a PrintDocumentAdapter. The adapter can write PDF data to a file, allowing
the converter to avoid the Android print dialog.

## Asset rule

Keep assets used by the HTML beside the HTML:

paper.html
logo.png
illustrations/
    q1.png
    q2.png

Relative HTML references such as `src="logo.png"` or `src="illustrations/q1.png"`
will resolve from the HTML directory.

## Reuse

You do not need to change the HTML-to-PDF code for each exam.

Every Gemini output can use the same command:

python html_to_pdf.py "INPUT.html" "OUTPUT.pdf"

The only thing that changes is the Gemini-generated HTML and its asset files.
